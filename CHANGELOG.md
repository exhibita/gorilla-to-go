# What is new in Gorilla To Go

The newest version is first. Each version has the date when it went live.

## 0.14.0 — 2026-10-21

- Links pages: a page of link buttons, for example for a social media profile. The site needs Vanilla Gorilla template version 3.
- In the editor, the Links view has the picture above the title and the list of links. Tap a link to change its text, its address or its place.
- The app checks each address as the site does. Type the full address, with https:// at the start, or use mailto:, tel: or sms:.
- Details of a links page has a sitemap switch and a field for the CSS of the page.
- The upgrade page has the steps for template version 3.

## 0.13.0 — 2026-10-21

- Security review of the app. The app now refuses to run inside another website's page.
- Add a site: the app tells you when the branch name is not a name that git accepts.
- Remove a site: the dialog tells you that the token still works on GitHub, and where to delete it.
- The project has a security policy. SECURITY.md on GitHub says how to report a security problem.

## 0.12.0 — 2026-10-19

- Tap the version number in the About box to see what is new.
- When you are offline, the app shows the last 3 versions. When you are online, it shows all versions.

## 0.11.1 — 2026-10-19

- Add a site: when a repository of an organization is not found, the app tells you what to check on the token.
- The token help has a new section for sites that belong to an organization.

## 0.11.0 — 2026-10-19

- Editor: when you press Enter in a list, the next item starts. Press Enter on an empty item to end the list.
- Numbered lists count on, task lists start an open task, and quotes continue.
- The Pages list follows your last publish also after the app opens again.
- Restore turns Details and Photos on or off correctly.

## 0.10.0 — 2026-10-19

- New help page: Install the app. It has the steps for iPhone and Android, and works offline.
- In a browser tab, the Welcome screen tells you to install the app first.
- The About box links to the install help.

## 0.9.0 — 2026-10-19

- Drafts: turn on Draft in Details, then tap Save draft. The page is saved on GitHub, but the site does not show it.
- The Pages list has a Drafts filter.
- Publish status: after you publish, the app shows Publishing, Live or Build failed, with a link to the build on GitHub.

## 0.8.0 — 2026-10-18

- Galleries: a Photos view for gallery pages. Add several photos at once, write alt text and captions, change the order, and remove photos.
- The first photo is the cover of the gallery.
- Preview shows the photos in a grid, as the site does.

## 0.7.0 — 2026-10-18

- Add photos to a page with the image button in the editor.
- The app makes each photo at most 1600 pixels wide and removes the location data.
- The page and its photos go to GitHub in one commit, so the site builds one time.

## 0.6.0 — 2026-10-18

- New About box: tap the ? button on the Pages list.

## 0.5.0 — 2026-10-18

- Delete a page, with a confirmation step.

## 0.4.0 — 2026-10-18

- Make a new page: a blog post, a page or a gallery.
- A new page stays on your phone until you tap Publish.

## 0.3.0 — 2026-10-18

- Edit a page and publish the change.
- The editor has a toolbar, a Preview and the Details (title, date and description).
- Your changes stay on your phone until you publish. If the page changed on GitHub, the app stops and does not overwrite it.

## 0.2.0 — 2026-10-18

- The Pages list, with search and filters for blog posts, pages and galleries.
- Open a page to read it. The list and the pages also work offline.

## 0.1.0 — 2026-10-18

- First version: add a site with a GitHub token. The app checks the token and the site.
- Light and dark themes. The app works offline.
